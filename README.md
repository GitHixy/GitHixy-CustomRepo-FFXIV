# GitHixy's Dalamud Plugins

**A custom plugin repository for Final Fantasy XIV, with all my [Dalamud](https://github.com/goatcorp/Dalamud) plugins in one place.**

Add it once and you can install, and get automatic updates for, every plugin listed below straight from the in-game plugin installer.

## How to add the repository

1. In game, type `/xlsettings` to open the Dalamud settings.
2. Go to the **Experimental** tab.
3. Under **Custom Plugin Repositories**, paste this URL in the empty field:

   ```
   https://raw.githubusercontent.com/GitHixy/GitHixy-CustomRepo-FFXIV/main/repo.json
   ```

4. Click the **+** button, then the **Save** icon at the bottom right.
5. Open the plugin installer with `/xlplugins` and search for the plugin you want.

## A note on custom repositories

Plugins from custom repositories are not reviewed by the Dalamud team. Everything here is open source: each plugin links to its code, and every download is built from that code by GitHub Actions, not on my machine.

When a plugin is accepted into the official repository, I'll remove it from here. If you installed it from this repository, you may need to reinstall it from the official list to keep getting updates.

## Bugs, ideas and support

Every plugin has a **Diagnostics** page in its settings that copies a bug report for you. Open an issue on that plugin's GitHub page, or come and talk about it on [Discord](https://discord.gg/9kjUjWDBkJ).

If you enjoy my plugins and want to support their development, you can do it on [Patreon](https://www.patreon.com/GitHixy). Thank you!
